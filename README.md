# Gestión de Tareas

Programa básico hecho en Python para administrar tareas.

## Funciones

* Agregar tareas.
* Ver las tareas.
* Mostrar el progreso.
* Ver cuántas tareas están completadas.

## Función agregada

Se agregó `mostrar_progreso()` para calcular el porcentaje de tareas completadas.

Si no hay tareas, muestra:

`Sin tareas`c

## Cómo probar

Ejecutar:

```bash
python main.py
```

Luego usar las opciones del menú.
